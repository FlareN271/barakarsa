❓ Panduan Singkat

Projects vs Labels
Project adalah folder — satu task hanya masuk satu project (KipApp, Kerja, Personal). Ubah nama, warna, atau penanda CKP lewat ⋯ di samping nama project. Label adalah penanda tambahan — satu task boleh punya beberapa label (Urgent, Review).

Menu
🏠 Beranda tempat memulai hari: sampul, Bara, jam, task hari ini, dan widget. 📋 Belum selesai berisi semua task yang belum dicentang, dikelompokkan: Belum dipilah, Lewat tanggal, Hari ini, Besok, 7 hari ke depan, Nanti. 📅 Kalender, ✅ Selesai, dan 📈 Reporting tetap seperti sebelumnya. Di HP, menu ada di bilah bawah; ☰ Lainnya membuka project, label, dan menu lain. Beranda diatur lewat 🎨 Atur Beranda (tombol di sampul atau ⋯ → Tampilan); sampul unggahan dan album disimpan di perangkat ini saja.

Tambah cepat
Tombol ➕, tombol Q, atau tekan lama ikon aplikasi. Ketik satu kalimat, mis. Rapat SE2026 besok 13.30 #kerja !1: tanggal (hari ini, besok, lusa, nama hari, 15 okt, tgl 15), jam (13.30, jam 9), #project, !1–!3 atau p1–p3 untuk prioritas, dan @label dikenali langsung. Ketuk ✕ di chip bila salah tebak. Enter menyimpan; Detail… membuka form lengkap. Task tanpa tanggal dan project masuk 📥 Belum dipilah. Task dari Tambah cepat berstatus Not Started.

Mencentang task
Task In Progress langsung selesai. Task Not Started, On Hold, atau Cancelled menanyakan dulu: ✓ Selesai atau ▶ Mulai kerjakan. Menghapus centang mengembalikan task ke status sebelum dicentang. Di menu ✅ Selesai ada kotak cari untuk menemukan task yang sudah selesai.

Priority
Bawaan: tanpa prioritas. Pilih Priority 1–3 hanya bila memang perlu ditandai; badge ⚑ hanya muncul untuk P1–P3. Pakai urutan ⇅ Prioritas untuk menampilkan P1 paling atas.

Mengurutkan task
Tahan ikon ⠿ di kiri task, lalu geser ke atas atau bawah untuk mengatur urutan pengerjaan.

CKP
Task di project bertanda Project CKP (bawaan: KipApp) yang sudah dipilih IKI-nya masuk ke menu ⋯ → CKP Triwulan. Task Title menjadi Uraian Kegiatan, Description menjadi Keterangan/Catatan. Di form task, ketuk kolom IKI untuk mencari IKI (nama kegiatan, tim, kode IK, teks IKI, atau rincian); tiga IKI terakhir dipakai tampil paling atas. IKI tim lain bisa dipilih, tetapi diberi tanda bukan penugasanmu. Setelah IKI dipilih, muncul 💡 saran keterangan dari task sebelumnya dengan IKI yang sama. Dari sana bisa dibuat Laporan PDF per IKI (lengkap dengan foto bukti dukung) dan Excel rekap CKP.

Pengingat
Menu ⋯ → 🔔 Pengaturan pengingat → Aktifkan di perangkat ini (lakukan di setiap HP/laptop). Task bertanggal dan berjam diingatkan sesuai bawaan (mis. 5 menit sebelumnya), atau pilih sendiri lewat 🔔 di bawah kolom Time. Ringkasan pagi berisi task hari ini. Notifikasi dikirim server dari task yang sudah tersinkron, jadi tetap muncul walau aplikasi ditutup.

Reporting
Pilih Minggu ini, Bulan ini, atau Triwulan ini. Task selesai dihitung menurut waktu dicentang; tepat waktu berarti selesai paling lambat pada tanggal task (atau Sampai tanggal). Task yang selesai sebelum 8 Oktober 2026 tidak punya catatan waktu selesai, jadi tidak dinilai tepat waktu atau terlambat. Ketuk Lewat tanggal untuk melihat task yang tertinggal.

Bara
Bara menyapa di Beranda sesuai waktu, ikut senang saat task dicentang (salah centang? ketuk ↶ Batal di baris hijau), dan bersorak di kotak Hari ini saat semua task hari ini beres. Mulai jam rekap sore (bawaan Senin–Jumat 15.55) kotak Hari ini berubah menjadi rekap: yang beres dan yang tersisa. Rekap sore juga dikirim sebagai notifikasi (atur di 🔔 Pengaturan pengingat). Ketuk Bara untuk kalimat lain. Nama yang dipakai Bara diatur di ⋯ → 👤 Nama panggilan (kosong = sapaan tanpa nama).

Tampilan
Menu ⋯ → Tampilan: Otomatis mengikuti mode gelap/terang perangkat, atau pilih Terang/Gelap. Pilihan disimpan per perangkat. Laporan PDF CKP selalu putih apa pun temanya.

Backup
Data tersimpan di perangkat ini dan, bila sudah masuk akun, tersinkron lewat server. Export JSON tetap disarankan secara berkala.
