❓ Panduan Singkat

Projects vs Labels
Project adalah folder — satu task hanya masuk satu project (KipApp, Kerja, Personal). Ubah nama, warna, atau penanda CKP lewat ⋯ di samping nama project. Label adalah penanda tambahan — satu task boleh punya beberapa label (Urgent, Review).

Priority
Priority 1 = paling penting/mendesak, sampai Priority 4 = paling ringan. Task baru otomatis Priority 4 (seperti Todoist). Pakai urutan ⇅ Prioritas untuk menampilkan P1 paling atas.

Inbox
Tempat menangkap ide cepat. Cukup ketik judul lalu Enter — tanggal, status, dan kuadran diisi belakangan lewat klik judul task.

Mengurutkan task
Tahan ikon ⠿ di kiri task, lalu geser ke atas atau bawah untuk mengatur urutan pengerjaan.

CKP
Task di project bertanda Project CKP (bawaan: KipApp) yang sudah dipilih IKI-nya masuk ke menu ⋯ → CKP Triwulan. Task Title menjadi Uraian Kegiatan, Description menjadi Keterangan/Catatan. Di form task, ketuk kolom IKI untuk mencari IKI (nama kegiatan, tim, kode IK, teks IKI, atau rincian); tiga IKI terakhir dipakai tampil paling atas. IKI tim lain bisa dipilih, tetapi diberi tanda bukan penugasanmu. Setelah IKI dipilih, muncul 💡 saran keterangan dari task sebelumnya dengan IKI yang sama. Dari sana bisa dibuat Laporan PDF per IKI (lengkap dengan foto bukti dukung) dan Excel rekap CKP.

Pengingat
Menu ⋯ → 🔔 Pengaturan pengingat → Aktifkan di perangkat ini (lakukan di setiap HP/laptop). Task bertanggal dan berjam diingatkan sesuai bawaan (mis. 5 menit sebelumnya), atau pilih sendiri lewat 🔔 di bawah kolom Time. Ringkasan pagi berisi task Today. Notifikasi dikirim server dari task yang sudah tersinkron, jadi tetap muncul walau aplikasi ditutup.

Tampilan
Menu ⋯ → Tampilan: Otomatis mengikuti mode gelap/terang perangkat, atau pilih Terang/Gelap. Pilihan disimpan per perangkat. Laporan PDF CKP selalu putih apa pun temanya.

Backup
Data tersimpan di perangkat ini dan, bila sudah masuk akun, tersinkron lewat server. Export JSON tetap disarankan secara berkala.
