❓ Panduan Singkat

                

                    
Projects vs Labels

                    Project adalah folder — satu task hanya masuk satu project (ASN, Work, Personal). Label adalah penanda tambahan — satu task boleh punya beberapa label (Urgent, Review).


                    
Kuadran Eisenhower

                    Do First = mendesak & penting. Schedule = penting tapi belum mendesak. Delegate = mendesak tapi bisa diwakilkan. Eliminate = tidak keduanya.


                    
Inbox

                    Tempat menangkap ide cepat. Cukup ketik judul lalu Enter — tanggal, status, dan kuadran diisi belakangan lewat klik judul task.


                    
Mengurutkan task

                    Tahan ikon ⠿ di kiri task, lalu geser ke atas atau bawah untuk mengatur urutan pengerjaan.


                    
CKP

                    Hanya task dengan project ASN yang masuk ke CKP Preview. Hasilnya berupa tabel siap tempel ke Google Docs.


                    
Backup

                    Data tersimpan di browser perangkat ini saja. Export JSON secara berkala agar aman kalau cache browser terhapus.
