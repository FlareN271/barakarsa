🔑 Buat Kunci Pengingat Barakarsa

Kunci dibuat di browser ini saja, tidak dikirim ke mana pun. Buat sekali, lalu salin ke Supabase. Membuat ulang berarti semua perangkat harus mengaktifkan pengingat lagi.

⚠️ VAPID_PRIVATE_KEY dan CRON_SECRET bersifat rahasia: hanya ditempel ke Supabase (Edge Functions → Secrets, dan SQL penjadwal). Jangan ditaruh di repo, chat, atau file yang diunggah.

  1. Edge Functions → Secrets: tambahkan VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT, CRON_SECRET dengan nilai di atas.
  2. SQL Editor → 02-penjadwal.sql: ganti TEMPEL_RAHASIA_PENJADWAL dengan nilai CRON_SECRET yang sama.
  3. Tutup halaman ini setelah selesai. Kunci tidak disimpan di mana pun.
